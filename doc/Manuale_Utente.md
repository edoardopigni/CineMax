# CineMax - Manuale Utente

**Autore:** Document & Quality Manager  
**Versione:** 1.0  

---

## 1. Introduzione
**CineMax** è un'applicazione software sviluppata in Java che gestisce il sistema di prenotazione e proiezione cinematografica direttamente da riga di comando (CLI). Il programma è progettato per essere leggero, veloce e intuitivo.

---

## 2. Requisiti di Sistema
Per poter eseguire correttamente CineMax sul proprio computer, è necessario disporre di:
*   **Java Runtime Environment (JRE):** Versione 17 o superiore installata e configurata nel PATH di sistema.
*   **Sistema Operativo:** Compatibile con Windows, macOS e Linux.

---

## 3. Guida all'Avvio (Primo Utilizzo)

1. Aprire il terminale (o Prompt dei comandi) del proprio sistema operativo.
2. Posizionarsi all'interno della cartella principale del progetto in cui è presente l'eseguibile o i file sorgente compilati.
3. Avviare l'applicazione digitando il comando:
   ```bash
   java -jar CineMax.jar
